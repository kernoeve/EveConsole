# AI Agent (Eden)

Eve Cortex ships with an optional built-in conversational assistant. It has
read access to the data in your local database via tool calls, so it can answer
questions the UI isn't explicitly designed for.

> The agent is entirely optional and inactive until you set it up. If you don't
> configure it, you can ignore it completely.

## What it can do

- Answer questions about your character/corp data by querying the local database.
- Run against an **external** provider (Claude or OpenAI) or a **local** model
  (e.g. Ollama).
- Optional **text-to-speech** (local Piper, or ElevenLabs) and **speech-to-text**
  (local Whisper, or OpenAI) for hands-free use.
- Customizable name and voice.
